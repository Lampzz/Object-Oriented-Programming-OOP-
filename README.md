# OOP Demonstration
This repository showcases Object-Oriented Programming concepts in Python using a Microwave class. It includes examples of:

Class attributes and methods

Encapsulation through instance variables

Custom methods to simulate microwave functionality (e.g., turn_on, turn_off, run)

Operator overloading with dunder methods (__add__, __mul__, __str__)

Explore this project to learn how Python brings OOP to life!
